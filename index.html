Tentang NalarDagang

Prototipe konsep startup berbasis web.

✦

NalarDagang mengusulkan integrasi Computer Vision untuk membantu inventarisasi stok dan Generative AI untuk pembuatan promosi. Versi ini dibangun hanya dengan HTML, CSS, dan JavaScript, tanpa server atau API eksternal.

Batasan prototipe: deteksi objek, prediksi restock, dan generator promosi masih berbasis simulasi atau aturan sederhana. Untuk implementasi nyata dibutuhkan model AI, pengujian dengan UMKM, serta perlindungan data yang sesuai.
